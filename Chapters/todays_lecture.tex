Let's now ask ourselves a question that, though seemingly similar to the unit distance problem, is actually quite different:
\begin{center}
    How many points in $\R^d$ can all be at pairwise unit distance?
\end{center}
In the unit distance problem, we \textit{fixed points} and \textit{counted unit distances}. Here, we haven't fixed any points.

It turns out the answer is $d + 1$, and is given by the standard simplex.

Let's study the properties of hypothetical points that would satisfy this condition to glean information that will help us figure out what they might be.

Let $v_0, v_1, \ldots, v_n \in \R^d$ be points such that $\norm{v_i - v_j} = 1$ for all $0 \leq i, j \leq n$ with $i \neq j$ and $\norm{v_i} = 1$ for $i \neq 0$. Without loss of generality, take $v_0 = 0$.

For all $i \neq j$, notice that % [CLAUDE] do I need i, j \geq 1 here? add that condition in if so
\begin{align*}
    1 = \norm{v_i - v_j}^2 = \cycl{v_i - v_j, v_i - v_j} = \cycl{v_i, v_i} - 2\cycl{v_i, v_j} + \cycl{v_j, v_j} = 2\parenth{1 - \cycl{v_i, v_j}}
\end{align*}
This tells us

What if I have two distances instead?

Suppose $p_1, \ldots, p_n \in \R^d$ are at pairwise distances $\set{\alpha, \beta}$. We want to define polynomials $f_i(\bx)$ such that for all $i, j$,
\begin{align*}
    f_i\of{p_j} = 
    \begin{cases}
        \alpha^2 \beta^2 & \text{ if } i = j \\
        0 & \text{ if } i \neq j
    \end{cases}
\end{align*}
We can define
\begin{align*}
    f_i(\bx) = \parenth{\norm{\bx - p_i}^2 - \alpha^2}\parenth{\norm{\bx - p_i}^2 - \beta^2}

\section{Eventown}

Wes reckons this place is close to Allentown. Gotta explore Eastern Pennsylvania some more.

The warm and friendly people of Eventown, Pennsylvania, love forming clubs. They do so in the following way.
\begin{enumerate}
    \item All pairs of clubs have an \underline{even} number of people in common.
    \item All clubs have an \underline{even} number of people.
\end{enumerate}
We can show that if there are $n$ people in Eventown, then there can be at most $2^{\frac{n}{2}}$ clubs.

Not too far from Eventown, Pennsylvania, is the town of Oddtown, Pennsylvania. A rather \textit{odd} place (\textit{even} more so than Eventown), Oddtown also has a lot of clubs, but in Oddtown,
\begin{enumerate}
    \item All pairs of clubs have an \underline{even} number of people in common.
    \item All clubs have an \underline{odd} number of people.
\end{enumerate}

\begin{boxtheorem}[Fisher's Inequality]
    Fix a collection $\A \ssq \Powset{[n]}$. If $\abs{A \cap B} = k$ for all distinct $A, B \in \A$, then $\abs{\A} = n$.
\end{boxtheorem}
\begin{proof}
    Let $v_A$ denote the incidence vector for $A \in \A$ (over $\R$). % [CLAUDE] add a note about what this means.
    We want to show that $\set{v_A}_{A \in \A}$ is linearly independent.

    Suppose $0 = \sum_{A \in \A} \lambda_A v_A$. Then
    \begin{align*}
        0
        &= \cycl{\sum_{A \in \A} \lambda_A v_A , \sum_{B \in \A} \lambda_B v_B} \\
        &= \sum_{A \in \A } \lambda_A^2 \abs{A} + \sum_{A \neq B} k \lambda_A \lambda_B \\
        &= k\parenth{\sum_{A \in \A} \lambda_A}^2 + \sum_{A \in \A}\parenth{\abs{A} - k} \lambda_A^2
    \end{align*}
    There is at most one $A_0 \in \A$ with $\abs{A_0} = k$. For $A \neq A_0$ we can get $\lambda_{A_0} = 0$. But then $\lambda_{A_0} = 0$ also. % [CLAUDE] polish this a bit and make it a bit
\end{proof}

Say we have $n$ points that are not all on a line. This means that they determine $\geq n$ lines.

Let $P$ be a set of points determining a set $L$ of lines. For a point $p \in P$, let $A_p$ be the set of lines in $L$ that are incident with $P$. For points $p \neq q$, would $\abs{A_p \cap A_q} = 1$ imply that $\abs{P} \leq \abs{L}$?

If not all points are on one line, then for all $p, q$, $A_p \neq A_q$. So there is a point $r$ that does not lie on the line $\bar{pq}$. Thus, the line $\bar{pr} \in A_p \setminus A_q$. Then $\bar{qr} \in A_q \setminus A_p$.

Yet another application.

Recall our Ramsey number bound $R(k) = R(k, k) \geq (k - 1)^2 + 1$.

Define a graph $G$ with vertex set $T = \binom{[k]}{3}$. In other words, the vertex set is the set of all subsets of $[k]$ of size $3$.

For $A, B \in T$, say $A \sim T$ if $\abs{A \cap B} = 1$. Using this relation, define the edge set of the graph $G$.

Fisher's Inequality tells us that $\omega(G) \leq k$, where $\omega(G)$ is the clique number (see \sorry). % [CLAUDE] add cross-ref in place of \sorry.

An independent set in this context would be a set $I$ with $\abs{I} \leq k$ where $\forall A, B \in I$, $\abs{A \cap B} \in \set{0, 2}$. In other words, we're living in oddtown!

We can then show $R(k) \geq \binom{k}{3}$.
