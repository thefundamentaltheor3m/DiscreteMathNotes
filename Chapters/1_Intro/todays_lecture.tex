\subsection{Adjacency Matrices}

We can represent the data of a hypergraph $H$ in a matrix, known as the adjacency matrix.

\begin{boxdefinition}[Adjacency Matrix]
    If $H$ is a hypergraph with $n$ vertices and $m$ hyper-edges, then the adjacency matrix of $H$, denoted $\Adj(H)$, is the unique $n \times m$ matrix $\parenth{a_{ij}}$ where
    \begin{align*}
        a_{ij} =
        \begin{cases}
            1 & \text{ if row $i$ lies in hyper-edge $j$} \\
            0 & \text{ otherwise}
        \end{cases}
    \end{align*}
\end{boxdefinition}

Given a hypergraph $H$, a family of distinct representatives is a collection $x_1, \ldots, x_m$ such that $x_i \in f_i$, where we have distinct hyper-edges $f_1, \ldots, f_m$ in $H$. Such a collection exists iff for any collection $C$ of edges,
\begin{align*}
    \abs{\bigcup_{f \in C} f} \geq \abs{C}
\end{align*}
In other words, the number of vertices in all the edges in the collection should be at least the number of edges in the collection. This is what Hall's Marriage Theorem tells us about hypergraphs.

We can, in fact, prove an even stronger statement than Hall.

\begin{boxtheorem}
    If $G$ is a bipartite graph with parts $A$ and $B$, if all degrees in $A$ are $d_1$ and all degrees in $B$ are $d_2$, with $d_2 \leq d_1$, then there is a complete matching of $A$.
\end{boxtheorem}
% [CLAUDE] include a picture of such a graph
\begin{proof}
    Given a set $S \ssq A$, there are $d_1 \abs{S}$ edges coming out of $S$ and going to the right. Then,
    \begin{align*}
        \abs{\Gamma(S)} \geq \frac{d_1\abs{S}}{d_2} \geq \abs{S}
    \end{align*}
    so we can just apply Hall. % [CLAUDE] add cross-ref (/integrate should do this anyway, but still worth saying explicitly)
\end{proof}

How large can a Sperner system be?

\begin{boxtheorem}[Sperner's Theorem]
    A Sperner system on $[n]$ can have at most $\binom{n}{\floor{n/2}}$ vertices.
\end{boxtheorem}

An intuitive way of arguing is to find perfect matchings between the $k$th layer and the $(k + 1)$th layer, but at some point, this starts to break down. And at what point is that? Before $k$ exceeds $n / 2$.

\begin{proof}
    Let $H$ be a Sperner system on $[n]$. Define
    \begin{align*}
        F = \set{\emptyset, \set{1}, \set{1, 2}, \set{1, 2, 3}, \ldots, \set{1, 2, \ldots, n}}
    \end{align*}
    Choose a random permutation $\pi \in S_n$, and define 
    \begin{align*}
        H_{\pi} = \setst{\pi(h)}{h \in H}
    \end{align*}
    Define the random variable
    \begin{align*}
        X = \abs{\setst{f \in F}{f \in H_{\pi}}}
    \end{align*}
    Note that we can express
    \begin{align*}
        X = \sum_{h \in H} \xi_{f, \pi}
    \end{align*}
    where $\xi_{h, \pi}$ is $1$ if $\pi(h) \in F$ and $0$ otherwise.

    Computing the expected value of $X$, we get
    \begin{align*} % [CLAUDE] define notation for expected value - should be \mathbb{E}
        E(X) = \sum_{h \in H} E\of{\xi_{h, \pi}}
    \end{align*}
    Let's now compute the expectation of $\xi_{h, \pi}$. This is the probability that the permutation $\pi \in S_n$ sends $h \in H$ to some element of $F$. Since you cannot modify sizes, the only possible element in $F$ to which $\pi$ can send $h$ is precisely the set $\set{1, 2, \ldots, \abs{h}}$. How many such $\pi$ can do this? We have to consider the way $\pi$ acts on the other $n - \abs{h}$ elements of $h$, because we know it sends $h$ to $\set{1, 2, \ldots, \abs{h}}$. Thus, the probability is
    \begin{align*}
        \binom{n}{n - \abs{h}} = \binom{n}{\abs{h}}
    \end{align*}

\end{proof}
